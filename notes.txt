1. Direct OpenSSL Configuration:

If you want to change it strictly for an OpenSSL-reliant application,
 you can edit /etc/ssl/openssl.cnf and adjust the CipherString
 security level. Setting SECLEVEL=0 or SECLEVEL=1 will lift the
 2048-bit minimum constraint enforced by SECLEVEL=2.

2. Microsoft Windows (SChannel)

Windows uses the SChannel SSP to manage TLS handshakes. You can
 configure minimum RSA key sizes via the Windows Registry.  Navigate
 to:
 HKLM\SYSTEM\CurrentControlSet\Control\Cryptography\Configuration\Local\SSL\00010002
 You can define or modify properties like MinimumRSABitLength to
 adjust the threshold.
